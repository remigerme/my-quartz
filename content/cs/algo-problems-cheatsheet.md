> [!example] Vertex cover
> **Data :** an undirected graph $G$ <br>
> **Problem :**  find a minimum cardinality set of vertices that covers all edges

> [!example] Hamiltonian path
> **Data :** an undirected graph $G$ <br>
> **Problem :**  is there a path going once and only once through each vertex ?

> [!example] SAT
> **Data :** a boolean formula <br>
> **Problem :**  is there an assignment of variables that make this formula true

> [!example] Independant set (stable)
> **Data :** an undirected graph $G$ and an integer $k$ <br>
> **Problem :**  does there exist a set with at least k vertices that do not
contain any pair of neighboring vertices ?

> [!example] Hitting set
> **Data :** a collection $C$ of $m$ subsets of $\{1, ..., n\}$  <br>
> **Problem :**  find a minimum cardinality subset of $\{1, ..., n\}$ that contains at least one element of each subset of $C$
